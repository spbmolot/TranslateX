---
description: Сборка TranslateX для Windows и проверка получившегося приложения.
---

Выполняйте команды из корня репозитория с активированным виртуальным окружением проекта.

1. Запустите тесты `python -m pytest -q`.
2. Выполните `.\build.bat`. Скрипт синхронизирует версию, собирает пакет PyInstaller и ZIP. При установленном Inno Setup 6 он также создаёт установщик.
3. Запустите `.\dist\TranslateX\TranslateX.exe`, выберите область экрана и проверьте перевод по сценарию `/smoke`. Завершите программу через меню значка в трее. Журнал находится в `%APPDATA%\TranslateX\translatex.log`.
4. Проверьте переносимый архив `dist/TranslateX.zip` и, если нужен установщик, соответствующий версии файл в `installer/Output/`.
