# TranslateX

TranslateX распознаёт текст в выбранной области экрана Windows и показывает перевод поверх оригинала. Можно переводить субтитры, диалоги в играх и текст в программах, где его нельзя выделить мышью. По умолчанию приложение переводит на русский через Google Translate.

## Скачать для Windows

**TranslateX 1.0.2** для Windows 10 и 11 (x64). Python уже входит в сборку.

- [Скачать установщик (.exe)](https://github.com/spbmolot/TranslateX/releases/download/v1.0.2/TranslateX_Setup_1.0.2.exe) — запустите файл и следуйте подсказкам.
- [Скачать переносимую версию (.zip)](https://github.com/spbmolot/TranslateX/releases/download/v1.0.2/TranslateX.zip) — распакуйте архив целиком и откройте `TranslateX.exe` в папке `TranslateX`.

## Запуск из исходников

Проверено на Windows x64 с Python 3.12. Скачайте исходники через **Code → Download ZIP** и распакуйте архив либо клонируйте репозиторий командой `git clone https://github.com/spbmolot/TranslateX.git`. Откройте PowerShell в папке с `main.py` и выполните команды по порядку.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

При запуске появится рамка захвата. При первом нажатии **Старт** EasyOCR может скачать модели распознавания. Для этой загрузки нужен интернет.

## Как перевести область экрана

1. Нажмите **Ctrl+Alt+F8** и выделите мышью нужную область. Можно также перетащить готовую рамку за верхнюю панель и изменить её размер за край или угол.
2. Нажмите **Старт** на панели. По мере изменения текста в рамке перевод будет обновляться. Кнопки **Пауза** и **Стоп** управляют текущим переводом.
3. Чтобы вернуть закрытую рамку, щёлкните значок TranslateX в области уведомлений Windows. Через его контекстное меню можно перевести весь экран, скопировать последний перевод или выйти из приложения.

## Языки и переводчики

Нажмите шестерёнку на панели. На вкладке **Языки** выберите исходный и целевой языки, на вкладке **Перевод** — переводчик.

| Переводчик | Как работает |
| --- | --- |
| Google Translate | Отправляет распознанный текст в Google. Ключ API не требуется. |
| DeepL | Отправляет распознанный текст в DeepL. Введите свой ключ DeepL API в настройках. |
| OPUS-MT | Переводит на процессоре. Нужна отдельная модель для выбранной языковой пары в формате CTranslate2. |
| TranslateGemma | Переводит локально с помощью llama.cpp на процессоре или совместимой видеокарте. Скачайте модель и движок в разделе **Локальные модели**. |

Распознавание текста выполняется на компьютере. Для работы без интернета заранее загрузите модели распознавания и выбранного локального переводчика. Настройки, журнал работы и кэш переводов находятся в `%APPDATA%\TranslateX`.

Модель OPUS-MT можно подготовить из исходной модели Helsinki-NLP. Для этого установите в окружение пакет `transformers`. Например, команда `.\.venv\Scripts\python.exe scripts\convert_opus_mt.py en ru --install` подготовит модель для перевода с английского на русский и поместит её в стандартную папку моделей приложения. [Скрипт конвертации](scripts/convert_opus_mt.py)

## Сборка и тесты

Следующая команда собирает приложение из созданного выше окружения. Запустите её в корне проекта.

```powershell
cmd /c "call .venv\Scripts\activate.bat && build.bat"
```

Скрипт создаст `dist\TranslateX\TranslateX.exe` и переносимый архив `dist\TranslateX.zip`. Для запуска из архива распакуйте его целиком и откройте `TranslateX.exe` в папке `TranslateX`. Если установлен Inno Setup 6, в `installer\Output` также появится установщик.

Для проверки исходников установите pytest и запустите тесты.

```powershell
.\.venv\Scripts\python.exe -m pip install pytest
.\.venv\Scripts\python.exe -m pytest -q
```
